# Obsidian-Forge

**Tags:** `magma`, `orange`, `dark`, `warm`

Forged in fire. Dark volcanic backgrounds with glowing orange and red accents.

## Palette

| Color | Hex | Usage |
|---|---|---|
| **Background** | `#120a08` | Dark obsidian |
| **Foreground** | `#ffe6cc` | Ash white |
| **Primary** | `#ff5500` | Magma Orange (Directory) |
| **Secondary** | `#592411` | Cooled rock (Separators) |
| **Accent** | `#ffcc00` | Sparks (Highlights) |
| **Error** | `#ff1a1a` | Lava red |
| **Success** | `#ff9933` | Stable heat |

## Activation

```bash
prism apply obsidian-forge
```
