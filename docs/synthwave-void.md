# Synthwave-Void

## Vibe
Synthwave-Void is a neon arcade wave: vivid violet, cyan, and gold streaks outline each science-fiction segment, making the prompt feel like a retro-futuristic console.

## Usage / Activation
- **Zsh:** `source themes/zsh/synthwave-void.zsh-theme`
- **Fish:** `source themes/fish/synthwave-void.fish`
- **Bash:** `source themes/bash/synthwave-void.sh`

## Example prompt
```
╭─ ◈ user@host • ~/staging
╰─  main* ★ 0 ↝
```
Two bold block rows keep Git, cwd, and status visually separated with bright separators.

## Recommended terminal settings
Use a dark (#090014) background with strong contrast, enable a Powerline-aware Nerd Font (JetBrains Mono, Fira Code Nerd Font), and let the bold/powerline glyphs shine. Moderate transparency (~80%) keeps the neon glow against the void backdrop.
