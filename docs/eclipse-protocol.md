# Eclipse-Protocol

**Tags:** `minimal`, `dark`, `purple`, `stealth`

A deep, high-contrast purple theme designed for covert operations and minimal distraction.

## Palette

| Color | Hex | Usage |
|---|---|---|
| **Background** | `#090011` | Terminal background |
| **Foreground** | `#e0d4fc` | Primary text |
| **Primary** | `#6c3fb5` | Directory, prompts |
| **Secondary** | `#452875` | Separators, dimmed text |
| **Accent** | `#9d65ff` | Highlights, git branches |
| **Error** | `#ff4060` | Errors, failures |
| **Success** | `#40ff99` | Success, clean state |

## Recommended Fonts

- **JetBrains Mono**: Excellent legibility for dense code.
- **Fira Code**: Great ligatures that match the geometric aesthetic.

## Activation

```bash
prism apply eclipse-protocol
```
