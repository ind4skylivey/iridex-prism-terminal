# Cyber-Noir

## Vibe
Cyber-Noir is a power-hungry neon opera with magenta, cyan, and electric yellow streaks flowing through every segment. It feels like Powerlevel10k on steroids—rich, gadget-laden, and alive with status cues.

## Usage / Activation
- **Zsh:** `source themes/zsh/cyber-noir.zsh-theme`
- **Fish:** `source themes/fish/cyber-noir.fish` (copy into your Fish prompt function for persistence).
- **Bash:** `source themes/bash/cyber-noir.sh` (drop that into `~/.bashrc`).

## Example prompt
```
╭─ time:13:28 • load:0.24 • bat:92% • 
╰─ user@host  ~/prism ( main*) ✔ 0 ↺
```

## Recommended terminal settings
Use a dark background (#05010b) with bold contrast. Enable a Powerline-aware Nerd Font (JetBrains Mono, Fira Code Nerd Font) and keep bold text on. Reduce opacity only slightly (80–90%) so the neon glow stays crisp on modern monitors. A little padding helps the blocks breathe while the second line stays readable.
