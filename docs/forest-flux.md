# Forest-Flux

## Vibe
Forest-Flux is calm and legible: soft greens and warm ambers inspired by evergreen woods. It keeps segments organized but never jittery, so it’s great for long coding sessions.

## Usage / Activation
- **Zsh:** `source themes/zsh/forest-flux.zsh-theme`
- **Fish:** `source themes/fish/forest-flux.fish`
- **Bash:** `source themes/bash/forest-flux.sh`

## Example prompt
```
╭ time:14:02 • user@host
╰ ~/code (main) ✔ 0 →
```
Gentle powerline bars separate time and context while the second line shows cwd, git, and success.

## Recommended terminal settings
Use a matte dark-green background, a comfort-oriented monospace font (Fira Code, Iosevka), and keep opacity low (~90%) to let the greens stay soft on the eyes. Horizontal padding helps the lines breathe.
