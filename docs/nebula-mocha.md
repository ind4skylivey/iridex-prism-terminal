# Nebula-Mocha

**Personality:** Nebula-Mocha feels like a cozy lounge in the clouds—velvet dark, pastel highlights, and a gentle glow separating each segment.

**Usage:** Source `themes/zsh/nebula-mocha.zsh-theme` (or the Fish/Bash equivalents) for a two-line prompt with powerline-style bars that keep your Git branch, status, and working directory easy to scan.

**Example prompt:**
```
╭─ user@host  ~/prism-ideas
╰─  main ✦ 0 →
```

**Recommended settings:** Use a dark terminal background with subtle blur/transparency (20–30%), pair with a monospaced font featuring clean powerline glyphs (e.g., Nerd Font, JetBrains Mono), and keep terminal padding generous so the airy two-line layout breathes.
