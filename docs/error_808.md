# ERROR_808

**Personality:** ERROR_808 is a rogue console patchwork—glitchy, frantic, and teasing collapse at every keystroke.

**Intended Use:** Great for high-energy sessions when you want the terminal to feel unstable yet powerful. It reminds you of the digital frontier with every warning.

**Prompt Example:**
```
▒▓ ERROR_808 ▓▒
⚠ user@host ▓▒ ~/site ⚠ main ✗ ✖ (2) ▓▒
```
**Recommended Settings:** Crank contrast, disable transparency, and enable bold/italic styles. A slight noise overlay and a Nerd Font keep icons sharp (⚠, ✖, ▒).
