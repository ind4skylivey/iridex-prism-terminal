# Glitch-Grid

## Vibe
Glitch-Grid is an aggressive, blocky console that lives on the edge: magenta, lime, and cyan glyphs flash over a black grid, and errors trigger inverted colors and big warning icons.

## Usage / Activation
- **Zsh:** `source themes/zsh/glitch-grid.zsh-theme`
- **Fish:** `source themes/fish/glitch-grid.fish`
- **Bash:** `source themes/bash/glitch-grid.sh`

## Example prompt
```
ERROR
▌ ~/site  main ● ✖ 2
```
The layout starts with a labeled header row and drops into a second line that combines cwd, git, and exit status with loud glyphs.

## Recommended terminal settings
Use a pitch-black background (#050200), a bold Nerd Font (JetBrains Mono, Hack), and enable bold text with high contrast. Minimal opacity keeps the red/yellow warning palette sharp. Consider tilting the font size slightly larger to let the blocks breathe.
