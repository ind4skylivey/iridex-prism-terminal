# Midnight-Warp

## Vibe
Midnight-Warp is tuned for modern terminals (Warp, Ghostty) with clean alignment, glassy highlights, and an optional right-aligned info strip that feels at home in polished UIs.

## Usage / Activation
- **Zsh:** `source themes/zsh/midnight-warp.zsh-theme`
- **Fish:** `source themes/fish/midnight-warp.fish`
- **Bash:** `source themes/bash/midnight-warp.sh`

## Example prompt
```
╭ time:12:45 • user@host
╰ ~/app [main*] ✔ 0 →
```
The first line shows time and user, while the second line keeps cwd/git/status tidy with a soft accent.

## Recommended terminal settings
Choose a clean dark theme with slight transparency (~15%), a rounded modern font (JetBrains Mono, Inter), and enable right-aligned metadata if the terminal supports it. Keep tabs/padding consistent so the two rows align beautifully.
