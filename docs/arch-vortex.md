# Arch-Vortex

**Tags:** `arch-linux`, `cyan`, `dark`, `minimal`

A tribute to the Arch Linux aesthetic. Deep gray backgrounds with vibrant cyan accents and cool blues.

## Palette

| Color | Hex | Usage |
|---|---|---|
| **Background** | `#0f0f0f` | Terminal background |
| **Foreground** | `#e6f2ff` | Primary text |
| **Primary** | `#1793d1` | Arch Blue (Directory, prompts) |
| **Secondary** | `#455a64` | Subtle separators |
| **Accent** | `#00d3d3` | Vivid Cyan (Highlights) |
| **Error** | `#ff4d4d` | Errors |
| **Success** | `#2ecc71` | Success |

## Activation

```bash
prism apply arch-vortex
```
