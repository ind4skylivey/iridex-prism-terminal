# Lavender-Core

**Personality:** Lavender-Core feels like an ethereal anime hacker queen—calm yet unstoppable, whispering commands through soft neon fog.

**Intended Use:** Best when you crave a soothing focus mode: pastel gradients, airy spacing, and a gentle shimmer remind you that the terminal is a calm, creative studio.

**Prompt Example:**
```
◆ user@host ⟆ ~/projects
❧ main ⚡ 7 → 
```
**Recommended Settings:** Use moderate transparency (25–35%), enable soft blur, and pair with a glyph-friendly font (JetBrains Mono, Nerd Font). The icons ◆ and ⟆ complete the vibe.
