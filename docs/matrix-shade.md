# Matrix-Shade

## Vibe
Matrix-Shade channels a classique green-on-black hacker matrix aesthetic with clean segments, subtle command-duration info, and vi-mode cues while staying practical for daily use.

## Usage / Activation
- **Zsh:** `source themes/zsh/matrix-shade.zsh-theme`
- **Fish:** `source themes/fish/matrix-shade.fish`
- **Bash:** `source themes/bash/matrix-shade.sh`

## Example prompt
```
╔═ node@host | ~ (main*)
╚═ ■ 0 [main 0s]
```
The two-line prompt mimics falling code blocks, with right-hand metadata and status glyphs.

## Recommended terminal settings
Use a true black background (#020402), an ultra-clean mono font like IBM Plex Mono or JetBrains Mono, and enable bold text + high-contrast mode. Slight opacity (5–10%) keeps the Matrix glow while still being readable.
