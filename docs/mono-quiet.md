# Mono-Quiet

## Vibe
Mono-Quiet is a focused, nearly monochrome prompt stripped to the essentials: cwd, git, and status markers, with just a whisper of accent color.

## Usage / Activation
- **Zsh:** `source themes/zsh/mono-quiet.zsh-theme`
- **Fish:** `source themes/fish/mono-quiet.fish`
- **Bash:** `source themes/bash/mono-quiet.sh`

## Example prompt
```
~/code [main*] 0 »
```
The layout lives on one line with tiny brackets for Git and a discreet arrow for the next command.

## Recommended terminal settings
Use a pure black background, disable transparency, and set a neutral mono font (Fira Code, IBM Plex Mono) with small padding. The tiny pastel accent stays readable without disrupting focus.
