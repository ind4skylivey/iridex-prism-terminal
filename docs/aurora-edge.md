# Aurora-Edge

## Vibe
Aurora-Edge mixes cool blues with pink and cyan highlights inspired by Catppuccin Frappe. It puts project-state metrics up front so you always know which branch, container, or cluster you’re in.

## Usage / Activation
- **Zsh:** `source themes/zsh/aurora-edge.zsh-theme`
- **Fish:** `source themes/fish/aurora-edge.fish`
- **Bash:** `source themes/bash/aurora-edge.sh`

## Example prompt
```
╭ user@host ~/workspace
╰ (main*) docker 🐳 k8s ☸ ✔ 0
```
The second line summarizes git, docker, and k8s contexts while still being gentle on the eyes.

## Recommended terminal settings
Use a navy-to-indigo background, a soft glow font (JetBrains Mono, Fira Code Nerd), and keep opacity moderate (80–90%). Let the accent colors highlight project context without overwhelming the view.
