# Custom

**Tags:** `custom`, `user-defined`, `neutral`

Starter palette intended for users to tweak and extend. Soft dark background with neon primaries and balanced cyan secondary tones.

## Palette

| Color | Hex | Usage |
|---|---|---|
| **Background** | `#0b0b0b` | Terminal background |
| **Foreground** | `#f8f8f2` | Primary text |
| **Primary** | `#ff79c6` | Prompt glyphs, directory path |
| **Secondary** | `#8be9fd` | Username, separators |
| **Accent** | `#bd93f9` | Git branch, highlights |
| **Error** | `#ff5555` | Error state |
| **Success** | `#50fa7b` | Success state |

## Activation

```bash
prism apply custom
```
