# Terminal-Ghost

## Vibe
Terminal-Ghost is an ultra-cool, semi-monochrome spirit guardian for transparent tiling setups. Almost-ghostly grays and a single ice-blue accent keep the interface calm, while the tiny glyphs convey status without stealing attention.

## Usage / Activation
- **Zsh:** `source themes/zsh/terminal-ghost.zsh-theme`
- **Fish:** `source themes/fish/terminal-ghost.fish` (or copy it into `~/.config/fish/functions/fish_prompt.fish`).
- **Bash:** `source themes/bash/terminal-ghost.sh` (add that line to `~/.bashrc`).

## Example prompt
```
user@host ~/workspace [main] ● 0 ›
```
The compact one-line layout delivers cwd + git + status with subtle glyphs and relies on the accent dot to show clean vs dirty.

## Recommended terminal settings
Use a tiling terminal with ~10–20% opacity over a smoky glass wallpaper. Choose a thin monospace font that includes Nerd Font glyphs (JetBrains Mono Light, Mononoki) and keep window padding tight. Disable italics and let the contrast stay soft to preserve the whispering aesthetic.
